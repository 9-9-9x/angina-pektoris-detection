# Angina Pektoris Detection System

Sistem deteksi Angina Pektoris berbasis Machine Learning dengan Laravel + React frontend dan Python FastAPI backend.

## 🚀 Quick Start

### 1. Setup (First Time Only)

```bash
# 1. Install ML dependencies
cd ml
# Create virtual environment (if not exists)
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 2. Train the model (generates angina_model.pkl)
python model.py

cd ..

# 3. Setup Web App
cd web
./setup.sh
```

### 2. Start Services

#### Option A: Manual (4 Terminals)

```bash
# Terminal 1: ML API
cd ml
source .venv/bin/activate
uvicorn api:app --reload --port 8000

# Terminal 2: Laravel Server
cd web
php artisan serve --port 8001

# Terminal 3: Frontend Build
cd web
npm run dev
```

#### Option B: Using Script (Single Command)

```bash
./start-services.sh
```

### 3. Access Application

- **Web App:** http://localhost:8001
- **ML API Docs:** http://localhost:8000/docs
- **ML Health Check:** http://localhost:8000/health

## 📋 Perbedaan model.py vs api.py

| Script | Tujuan | Kapan Dijalankan | Output |
|--------|--------|------------------|--------|
| **model.py** | Melatih model | Sekali (atau saat retrain) | `angina_model.pkl` |
| **api.py** | Menyajikan prediksi | Terus menerus (server) | HTTP API |

**Penting:**
- `model.py` = **Build** the brain (train once)
- `api.py` = **Use** the brain (serve forever)

## ⚠️ Troubleshooting

### "ML Service Tidak Tersedia"

**Penyebab:** Service FastAPI belum dijalankan

**Solusi:**
```bash
cd ml
source .venv/bin/activate
uvicorn api:app --reload --port 8000
```

### "Model file not found"

**Penyebab:** Belum melatih model

**Solusi:**
```bash
cd ml
source .venv/bin/activate
python model.py
```
