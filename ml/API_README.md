# FastAPI - Angina Pektoris Detection API

REST API untuk prediksi Angina Pektoris menggunakan model Machine Learning (Random Forest).

---

## 🚀 Quick Start

### 1. Pastikan Model Sudah di-Train

```bash
cd ml
source .venv/bin/activate
python model.py
```

Pastikan file `angina_model.pkl` sudah terbuat.

### 2. Install Dependencies (jika belum)

```bash
pip install -r requirements.txt
```

### 3. Jalankan API

```bash
# Development mode (auto-reload)
uvicorn api:app --reload --host 0.0.0.0 --port 8000

# Production mode
uvicorn api:app --host 0.0.0.0 --port 8000
```

### 4. Akses Dokumentasi

Buka browser dan kunjungi:
- **Swagger UI**: http://localhost:8000/docs
- **ReDoc**: http://localhost:8000/redoc

## 📋 Field Descriptions

### Input Fields

| Field | Type | Description | Contoh |
|-------|------|-------------|--------|
| `usia` | integer | Usia pasien (0-120 tahun) | 65 |
| `jenis_kelamin` | string | "L" (Laki-laki) atau "P" (Perempuan) | "L" |
| `TD` | integer | Tekanan darah sistolik (mmHg) | 150 |
| `riwayat_DM` | string | Riwayat Diabetes: "Ya" atau "Tidak" | "Ya" |
| `HT` | string | Hipertensi: "Ya" atau "Tidak" | "Ya" |
| `riwayat_PJK_terdahulu` | string | Riwayat PJK: "Ya" atau "Tidak" | "Tidak" |
| `nyeri_dada_menjalar_ke_lengan` | string | Nyeri menjalar: "Ya" atau "Tidak" | "Ya" |
| `durasi_nyeri` | string | Format: "{angka} {satuan}" | "10 menit", "2 jam", "1 hari" |
| `sesak_napas` | string | Sesak napas: "Ya" atau "Tidak" | "Ya" |
| `mual` | string | Mual: "Ya" atau "Tidak" | "Tidak" |
| `muntah` | string | Muntah: "Ya" atau "Tidak" | "Tidak" |
| `keringat_dingin` | string | Keringat dingin: "Ya" atau "Tidak" | "Ya" |

### Output Fields

| Field | Description |
|-------|-------------|
| `prediction` | Hasil prediksi: "Angina Pektoris" atau "Bukan Angina Pektoris" |
| `prediction_code` | Kode numerik: 0 (Non-Angina) atau 1 (Angina) |
| `probability_angina` | Probabilitas Angina (0.0 - 1.0) |
| `probability_non_angina` | Probabilitas Non-Angina (0.0 - 1.0) |
| `risk_level` | Tingkat risiko: "LOW", "MODERATE", "HIGH" |
| `risk_percentage` | Persentase risiko (0-100%) |
| `confidence` | Tingkat kepercayaan: "High", "Moderate", "Low" |
| `features_used` | Fitur yang digunakan setelah preprocessing |
| `disclaimer` | Peringatan penggunaan |

## 🔧 Production Deployment

### Using Gunicorn (Recommended)

```bash
gunicorn api:app -w 4 -k uvicorn.workers.UvicornWorker --bind 0.0.0.0:8000
```

Options:
- `-w 4`: Number of worker processes (adjust based on CPU cores)
- `-k uvicorn.workers.UvicornWorker`: Worker class for ASGI

### Using Docker

Create `Dockerfile`:

```dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 8000

CMD ["uvicorn", "api:app", "--host", "0.0.0.0", "--port", "8000"]
```

Build and run:

```bash
docker build -t angina-api .
docker run -p 8000:8000 angina-api
```

## 🐛 Troubleshooting

### Model Not Found Error

```
ERROR: Model file 'angina_model.pkl' not found!
```

**Solution**: Run `python model.py` first to train and save the model.

### Port Already in Use

```
ERROR: [Errno 48] Address already in use
```

**Solution**: 
```bash
# Find and kill process using port 8000
lsof -ti:8000 | xargs kill -9
# Or use different port
uvicorn api:app --port 8080
```

### CORS Issues (Frontend)

The API includes CORS middleware allowing all origins. For production, restrict to specific origins:

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["https://your-frontend-domain.com"],
    allow_credentials=True,
    allow_methods=["POST"],
    allow_headers=["*"],
)
```
